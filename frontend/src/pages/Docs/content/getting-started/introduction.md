## 这是什么

EpochX 是一个记录学习状态的工具。它把你每天的学习情况记下来，算出你的状态读数，再让你自己决定下一步做什么。

它不替你安排学习，也不催你。它做的是一件比较基础的事：**让你看见自己这段时间是怎么学过来的**。

## 它为谁做的

主要面向中学生。已经习惯了分数、排名、家长和老师的评价，但这几样东西都不会告诉你"我今天为什么学不进去"。EpochX 想补的是这一块。

## 能做什么

现在能用的功能：

- **记录**：记一次学习、记一道错题、记一段专注时间
- **读数**：按学科给出当天的状态读数（高效稳定 / 疲劳预警 / 情绪受阻 / 波动上升）
- **计划**：根据你已有的记录生成一份学习计划，拆成任务
- **计时**：一次专注从开始到收尾，中间可以分段
- **复盘**：把一段时间的状态和知识一起回看
- **建议**：记录之后生成下一步可以做什么的建议
- **目标**：设一个长期目标，下面挂若干短期目标
- **知识库**：按学科查知识点，看每个知识点的掌握程度
- **用量**：看这个月用了多少

还在做的：[AI 对话](/docs/features/ai-chat) 与 [社区参照](/docs/features/community)。这两块在目录里标着「开发中」。

## 它不是什么

- **不是补课工具**，不提供课程、不提供老师
- **不是提分工具**，不承诺提分，也不预测分数
- **不是监督工具**，不会因为你没学而提醒你
- **不打分**，不给你排位

## 记录的单位是学科

状态读数、掌握度、错题都按**单个学科**分开展示，不做跨学科合并。

比如你可能同时有「数学 · 疲劳预警」和「语文 · 高效稳定」。我们不把它们揉成一个"今天状态如何"的结论——因为把两个不同学科揉在一起，那个数字对谁都没有意义。

## 隐私

默认的边界写在[隐私与安全](/docs/privacy/what-we-collect)那一章。最要紧的一条：你的错题原文和学习记录不会被发到境外或第三方服务器处理。
