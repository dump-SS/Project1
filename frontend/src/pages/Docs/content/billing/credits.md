## 这是什么

EpochX 的模型调用成本怎么计量、在哪里查看。

**先说最重要的一句：pilot（封测）期间只记录用量，不扣费。** 不需要付款方式，也不会产生账单。落地页顶栏「定价」标着「暂无」，说的就是这件事。

## 计量口径

每一次真实的模型调用记一行，含：

- **调用类型** —— 聊天 / 内嵌 / 高级 / 多模态
- **推理档位** —— 快速 / 标准 / 深入
- **模型名**
- **输入 token 数、输出 token 数**
- **折算成本**

成本按 token 数折算。不同模型的单价不同，所以同一个操作在不同模型下的成本数字不一样。

## 在哪里看

设置里的[用量页](/docs/features/usage)，只读，按月筛选。

**只存数值，不存内容。** 记录里有 token 数、成本、档位、模型名——**没有提示词，也没有模型输出的内容**。

## 需要注意

### 只记录，不扣费

这一条在 pilot 阶段是硬口径。记成本是为了将来收费时能有数据依据，**不是现在向你收费**。

### 没有充值、没有套餐

用量页**没有任何购买入口**。它是只读的。

### 单价是内部口径

用量页上的成本数字是**内部记账口径**，不是应付金额。它面向的是我们自己算成本，不是面向账单。

不同模型单价不同，如果不理解这个，看到碎数字会以为算错了。

### 有次数限制的不是用量

真正有限制的是**生成类操作**的次数：

- 建议 —— 每天 5 次
- 复盘 —— 每天 1 次

这些限制是为了控制成本，和你的"用量"数字不是一回事。用得多但都不涉及生成，不会触发限制。

## 常见问题

**封测收费吗？**
不收。见上面第一句。

**以后会收费吗？**
正式版的价格方案还没定。定了会在[价格](/docs/billing/pricing)页写清楚。

**用量数字为什么这么小/碎？**
因为是按 token 折算的内部成本，不是账单。而且单价本身还在核定中。

**不用这些功能的话会有用量吗？**
纯本地的功能（记记录、看读数、查知识点）不涉及模型调用，不产生用量。
