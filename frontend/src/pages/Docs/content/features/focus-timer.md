## 这是什么

一次专注从开始到收尾。中途可以**分段**——比如"做了 25 分钟数学，中间去接水，又回来做了 15 分钟"。

计时是[学习记录](/docs/features/learning-records)的时长来源。计时结束、记录里填了时长，这条记录才会影响状态读数。

## 怎么用

### 开始

两个入口：

- [专注计时](/study-timer)页直接开始
- 从[计划](/docs/features/plans-tasks)里的某个任务开始，学科会自动带过来

### 计时中

- 中途可以**分段**，每段单独记
- 计时在服务端持久化，**刷新页面或断线重连后能恢复**（按当前模式）
- 可以在计时页呼出侧栏，做点别的再回来

### 结束

点结束后填一份收尾：

- 完成了多少（完整 / 部分 / 放弃）
- 几个感受项（可留空）

收尾会直接生成一条[学习记录](/docs/features/learning-records)。

## 需要注意

### 收尾的三项是可选的

完成情况是三项里唯一建议填的。专注度、疲劳、情绪、难度**留空是正常的**。

留空表示"这次没采集到"，系统会按实际有的项算。**留空不会被当成 0 分**——"感觉很差"和"没填"是两件事。

### 放弃也是有效数据

中途放弃不丢人，而且应该记。放弃本身是完成情况的一种，计入读数的方式和其他完成情况不同。

如果完全不记，状态读数就少了这一次的样本。

### 恢复规则

- 长时间不动的会话会被**判定为异常中断**，不计入记录
- 断线重连按开始时的模式恢复，不会中途换模式

### 不要开着不放

计时不结束，状态读数就一直缺这一段。收尾那一步才是真正算数的一步。

## 常见问题

**计时忘了关怎么办？**
异常中断的会话不会计入记录，不会把时长算错。可能需要手动删掉那个会话。

**计时页面刷新了会不会丢？**
不会。计时会话在服务端存着，刷新能恢复。

**能同时开两个计时吗？**
不能。一次一个。
