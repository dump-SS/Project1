## 这是什么

每次记录之后，系统按学科算出一个当天的状态读数。读数来自你的记录，不是问卷，也不是别人给的评价。

现在有四种读数：

| 读数 | 说的是什么 |
|---|---|
| **高效稳定** | 这次的完成度和正确率都在正常范围 |
| **疲劳预警** | 最近几次的疲劳自评偏高，或者完成度在掉 |
| **情绪受阻** | 情绪自评连续几次为负向 |
| **波动上升** | 同一个学科的读数起伏明显变大 |

## 怎么用

- 进[个人数据](/docs/features/learning-records)或首页的读数区，**按学科分别列出**
- 每个读数可以展开看**看是哪几项数据**推出来的
- 觉得读得不对，可以对读数给反馈，反馈会记下来

## 需要注意

### 读数是读数，不是对人的判断

"疲劳预警"说的是**最近这几条记录里的数字长这样**，不是"你这个人状态不行"。我们不会用它评价你，也不用它推断你的性格或态度。

数据不足的时候我们显示"数据不足"，不硬凑一个结论。**一条记录不产生读数。**

### 按学科分，不做综合

读数是**单个学科**的。你可能同时有「数学 · 疲劳预警」和「英语 · 高效稳定」。

我们不把它们合成一个"今天综合状态"。原因很简单：把不同学科揉成一个数，那个数对谁都没有意义——数学的疲劳和英语的正确率不在一个量纲上，合并之后互相抵消或互相放大，两种结果都不可信。

如果要做整体判断，可以自己在[复盘](/docs/features/review)里看。

### 读数只由记录驱动

**没有任何一条状态读数是问卷填出来的。** 你填的自评（专注度、疲劳、情绪、难度）只是记录的一部分，和完成度、正确率一起进公式。

自评留空是正常的，系统会按实际有的项算，缺项不会被当成 0 分。

### 反馈是可选的

对一条读数给"准 / 不准"的反馈，是帮我们改进公式的，**不影响你的数据**，也不影响后续读数怎么算。

## 常见问题

**为什么没有"综合状态"？**
上面说了，跨学科合并出来的数字不可信。我们宁可分开摆着。

**为什么是"波动上升"而不是"不稳定"？**
用词上我们避免带评价色彩的词。波动是现象描述，不是判断。

**读数会变吗？**
会。新记录进来会重算最近窗口的读数，早先的读数也会跟着变。它是滚动的，不是定论。
