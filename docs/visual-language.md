## 1. 品牌世界观

### 1.1 一句话主线

> **蓝色不是"科技蓝"，而是"你正在前进的那一点光"。**

把蓝色当成普通 SaaS 主色，结果就是一套普通的蓝白 dashboard。

### 1.2 产品温度：温和的同行者

- 不是冷静观察者（陌生），不是积极教练（又一个督促者）。
- 中学生已被分数、排名、家长、老师评判很多次 → EpochX **站在记录这一边**，让用户看见走过的地方，不急着下结论。

### 1.3 差异化：完全围绕学生个人

| | 上一代学习工具 | EpochX |
|---|---|---|
| 中心 | **题**（公共的，所有学生看到同一个产品） | **人**（状态/错因/画像只对你有意义） |
| 推论 | 离开用户照样成立 | **离开用户不成立** |

"完全围绕学生个人"最狠的表达不是"我们很懂你"，而是**"这个产品没有你就没有内容"**。

### 1.4 「纪元 / EpochX」的含义

- **Epoch** = 时代的分界（不是宇宙、不是时间线）；**X** = 你（未知数）。
- 不是"学习多了一条时间线"，是**学习换了一个时代**。
- ⚠️ **「时间线」不作为叙事词**：它是功能语言不是立场语言（太多产品有 timeline），且时间线是公共的轴、人只是轴上的点。轨迹/节点可作视觉元素，但不作主张。

### 1.5 "下一代感"怎么来：行业错位

教育行业网页都很朴素（白底、插画小人、提分鸡血横幅）。引入科技公司级的视觉精度，冲击力来自**与品类的反差**，不需要自吹。
> **看到不一样，就是下一代。**（比任何文案都有效）

## 3. 色板 v0.1（语义 token · 对比度已算）

| 语义 token | 日 | 夜 | 对比度（文字/底） |
|---|---|---|---|
| `--bg-page` | `#F7F7F5` | `#10161E` | — |
| `--surface-card` | `#FFFFFF` | `#1B222D` | — |
| `--border-hairline` | `#E3E1DC` | `#2A3542` | — |
| `--text-primary` | `#23211D`（暖墨，非纯黑） | `#E8EAED` | 14.8 : 1 ／ 15.1 : 1 |
| `--text-secondary` | `#6B6862` | `#9AA4B0` | — |
| `--brand-blue` | `#1B5DBF` | `#4AD1FF` | 5.8 : 1 ／ 10.3 : 1 |
| 状态 teal / amber / coral | `#0F6E56` `#BA7517` `#D85A30` | `#5DCAA5` `#EF9F27` `#F0997B` | — |
| 系统错误红 | `#A32D2D` | `#F09595` | — |

状态色取自现有设计系统色阶（teal/amber/coral/red 的 600 与 400 档），不另起一套。

### 3.1 两个底色的判据（可复用于后续所有底色评审）

- **浅色底必须比卡片暗一档**：深色底上投影几乎不可见，卡片浮起只能靠明度差 → 深色模式天然只能用明度差 → 浅色也必须明度差 → **纯白底在这个体系里是死路**（卡片无法比底更亮，只能退回边框+阴影，于是昼夜两套机制）。
- **暖度上限 = 单独看不出暖**：`#F7F7F5` 单独看不出米色，但卡片并排时边界清晰。一旦能指着说"这是米黄色"，配衬线即滑向教辅/古籍。
- **深色底选偏蓝而非偏黑/偏灰**：偏黑时亮蓝变成霓虹贴纸，偏灰把亮蓝压闷；偏蓝（H≈214 / S≈30% / L≈9%）是同色系提亮。
- **判据**：把 `#4AD1FF` 小色块放到底色上，问「这光是**贴上去的**，还是**从底里透出来的**」。

### 3.2 红色：不禁用，重分归属

> **红色属于「系统对自己的错误」，不属于「系统对学生的评价」。**

**主语测试**：省略主语时，出问题的是谁？——是学生 → 不用红（状态读数走 teal/amber/coral）；是系统 → 可用红（删除、撤回授权、网络失败、违规处置）。

## 4. 蓝色的两种存在

| 存在方式 | 形态 | 用于 |
|---|---|---|
| **作为「光」** | 大面积、低强度（光晕/场） | hero 光场、页尾、进行中的呼吸 |
| **作为「动作」** | 小面积、高强度 | 唯一主 CTA、焦点、点亮的节点 |

- 两个方向都不能越界：**大面积 × 高强度 = 霓虹**（撞题材禁令）；**只有光没有点 = 没有行动**。
- 蓝色出口只有三个 token：`--accent`（唯一主 CTA/焦点）、`--progress`（计时、流式、进度）、`--node-on`（掌握度点亮、完成态）。
- **不可用状态一律灰，不占用蓝色**：未上线 / 暂无的功能用**灰色描边标签或虚线边框**——顶栏「暂无」灰标签、hero「桌面端即将推出」虚线灰按钮位，是同一套语言，与"蓝色 = 可用 / 动作"形成对比。
- **强度上限由"这个区域要不要读字"决定**：有正文的区域（产品内、对话、卡片）→ 低强度光场；**页尾是全站唯一没有正文要读的区域** → 允许大面积、鲜明、流体渐变的 abstract background（见 §7.7）。

## 5. 字体规则（暂定，学自 Moonshot / Anthropic）

> **长段文本、小字等用衬线体；其他均用无衬线体。**

落到本品牌的解释：**衬线 = 已经留下来的东西；无衬线 = 正在发生的东西**——与"蓝色是动词"是同一套**时态**逻辑。

| 元素 | 字体 | 时态 |
|---|---|---|
| Hero slogan、第二屏品牌句、功能屏金句标题 | 无衬线 | 正在说 |
| 对话里产品的回复（较长） | **衬线** | 已写下来的 |
| 用户说的话（短句） | 无衬线 | 随口输入的 |
| 功能名小字、副文小字 | 衬线 | 注释 |
| 按钮、导航、数字、计时 | 无衬线 + 等宽数字 | 动作/读数 |

副产品：同一段对话内产品衬线、用户无衬线 = "你说的话被它写下来了"。

⚠️ **中文衬线选型坑**：宋体做长文易滑向教科书/论文（教辅味）。建议**思源宋体（Source Han Serif）Regular + 字重不上 Bold + 行高约 1.8**，靠行高与字重克制去教辅味，不靠换字体。**待真排版时验证。**

## 6. 文案红线

### 6.1 禁用

冲刺、升级、你真棒、超越自己、满血复活、**提升自我**、**优先时代**（"优先"是竞争语汇，与不排名立场冲突）、惊人、落后、太少。

### 6.2 同行者文案规则

- 陈述观察，不下判词（**表扬同样克制**：只陈述行为"你把它收进错题本了"，不评价品质"习惯很好"）。
- 动词留给用户；用过去式留存，不追责。
- 一次一句轻话，不趁热督促；数字只说事实，不加评价。
- **内部术语不得外泄**：画像/归因/状态画像/掌握度等词只用于内部，不进学生可见文案。
- **退格检验**：这个词放进 hero 的退格初稿里会被删掉吗？会，就不要写。

## 7. 落地页结构（七屏 + 页尾）

**落地页讲"为什么值得开始"，产品内讲"现在怎么继续"。** 落地页是书的封面（可以有情绪、强动效），产品内是内页（安静、耐读）。

| # | 屏 | 内容 | 状态 |
|---|---|---|---|
| 1 | **Hero** | 上光下人：上部 2/3 光场（大品牌色光晕 + 呼吸 + 交互），底部地平线上左 logo+slogan、右动作区 | ✅ 定 |
| 2 | **三时代视窗** | 斜向平行四边形窄视窗（斜角 = logo X 斜体角度）=「时间切片」；窗内横向滚动实景图：古代书简 → 书山题海 → logo；logo 入窗后视窗右移 + 横向扩大 | ✅ 定 |
| 3–5 | **功能屏 ×3** | 标题 = 该屏对话里产品说过的原句（加「」+ 逐字打出 + 屏间切换动效）；证据 = 真对话 | ✅ 方向定 |
| 6 | **信任屏** | 横向劫持滚动，四张卡片（标题「隐私安全当为先。」） | ✅ 定 |
| 7 | **图标海屏** | 功能图标按"学生的一天"顺序无缝浮动滚动 | ✅ 定 |
| 8 | **CTA + 页尾** | 末句英文翻转 + 品牌光效页脚 | ✅ 定 |

### 7.0 顶栏（全局，跨屏）

- **logo 两态**：停留 hero 内时只显示 **EX 标**（`logo-mark`）；**滚过 hero 后全称 `EpochX` 从标识侧滑出**并全程保持。滑出语言与 hero 的"删词 / 写字"同族（标识也是从部分到完整）。
- **现阶段三个选项**：产品 / 定价 / 资源。
- **悬停展开**：鼠标移到任一选项上，**整个顶栏下拉展开**为大型面板，同时**页面背景失焦虚化**。
  - **产品**：最左「探索围绕你的下一代产品」+ 列表：EpochX Web、EpochX 桌面端。
  - **定价**：**无展开面板**；选项后带一个**框住的小字「暂无」**（灰色描边标签，见 §4）。pilot 期间支付推迟（#30），"暂无"本身就是真话，不编造定价信息。
  - **资源**：最左「你需要的一切，在此获得最新动态和保持联系」+ 列表：文档、媒体、更新日志、隐私政策。
- **滚动行为**：下滑自动收起、上滑弹出。⚠️ **信任屏横向劫持区间内禁用该行为，顶栏保持常显**（否则判断会被劫持逻辑吃掉而抖动）。
- **可达性**：桌面端 hover 之外**加 click + focus 同效，Esc 关闭**；移动端点击展开（复用 §7.6 的规则）。
- **虚化实现**：`backdrop-filter` + 半透明遮罩组合（blur 半径 8–16px）；低性能与 `prefers-reduced-transparency` 降级为**纯遮罩**。

✅ **三处冲突：两处已解，一处待确认**

1. **「定价」**（✅ 已定）：选项后标**框住的小字「暂无」**（灰色描边标签）。pilot 期间支付推迟（#30），"暂无"两个字就是全部真话。
2. **页尾对比度**（✅ 已定）：顶栏滚到页尾**加深遮罩**，不切文字颜色。
3. **资源列表的真实内容**（⏳ 待确认）：「媒体」可用**品牌素材包**（`frontend/public/brand/` 四张 logo，真实存在）；文档 / 更新日志 / 隐私政策属占位（隐私政策为 #29a 上线前补项）。

### 7.1 Hero

- **构图**：上光下人（光在前方/上方，内容在底部"地平线"上）。左说右做：左 logo + slogan，右动作区。
- **slogan 退格动效**：初稿「学习工具围着题转！」→ 删「题」「！」→ 打「你」「。」→ 成稿「学习工具围着**你**转。」
  - 两处修改 = 两个品牌动作：**题→你**（换中心 = 下一代）、**！→。**（降音量 = 温和）。
  - 别家品牌在首屏加词，我们在首屏删词。节奏：打完停 1s → 退格先快后慢 → 删到「题」前半秒停顿 → 句号落下光标熄灭。
- **暗纹 × 手电**（本屏专有）：背景为流动的学习物件 monoline 线稿（成绩单/书/文具/锥形瓶/地球仪/秒表…），静止时近不可见（`#2A3542` 档），鼠标像手电扫过才显形。题材过检：全是学科物件，非宇宙。
- **动作区三级阶梯**：输入框（主焦点，给想先说话的人）→ 即刻开始（ghost，给只想进来的人）→ 桌面端按钮位（虚线灰，**空位，等它来填**）。两入口都跳登录注册；桌面端可点性待定（disabled 或订阅通知）。
- 输入框 placeholder 候选：「先说一句，你今天怎么样？」；**草稿带过登录墙**（登录回来那句话还在）。

### 7.2 第二屏 · 三时代

- 三张实景统一**暗蓝 duotone**（历史沉蓝黑，只有 logo 是原色）。书山题海建议自拍（学生真试卷堆）比图库更有说服力。
- **光的调度是情绪拍**：历史段落主光收暗，logo 显现瞬间光回归 = 你的时代有光。
- **右侧文案（已定）**：「**AI 纪元，现围绕你构建。**」+ 小字「一款围绕你的 AI 学习产品」。「你」= `#4AD1FF`（该屏唯一蓝字）。
  - 「现」把换代感藏进时态，不用形容词。曾提议「最先进的学习助手」，因不可证明 + 与"同行者"冲突（助手=工具）而弃用。

### 7.3–7.5 功能屏 ×3

- **标题不新写**：直接取该屏对话里产品说过的原句（加「」、逐字打出）。整页只有 hero slogan 与第二屏品牌句是创作的文案，从第三屏起**让产品自己说话**。
- 每屏：左 = 金句大字标题 + 功能名小字；右 = 对话气泡（**1 句用户 + 2 句产品**，只删句子不改写）；光晕落在对话上；底部暗纹换主题物件。
- **每屏蓝色只一处**（光晕）。

| 屏 | 标题（= 对话原句） | 证据 |
|---|---|---|
| 三 · 状态读数 | 「坐了多久，和记住了多少，是两回事。」 | S2 |
| 四 · 错题路标 | 「错过的题，会变成路标。」 | S3 |
| 五 · 复盘回望 | 「回头的时候，路都在。」 | S4 |

- 顺序 = 由近及远（当下 → 事后 → 周期）。
- ⚠️ 一页四次打字机会腻 → 语义分工：**hero 是退格删词，功能屏是逐字写出**，一删一写构成呼应而非重复。

### 7.6 信任屏

- **横向劫持滚动**；四张卡片 = 标志 + 卡片 + 简要说明。
- 电脑端 hover → 展开实拍图 + 详细介绍（建议再加 click 同效 + Tab 可聚焦）；移动端配图不折叠 + 文字「展开」按钮。
- **横滚三护栏**：底部进度条 / 到底自动释放 / 支持触控板横滑与方向键。标题 sticky 在左。
- 四张卡：① 数据不出境（本地模型 / PRD 12.6）② 不评判·不排名（状态是读数 + 无榜单）③ 监护人可撤回（授权 + 撤回即删除）④ **不替你做决定**（配图 = S5 对话）。
- **标题（已定）**：「**隐私安全当为先。**」（Skyer 拍板）。曾提议「有些事，我们不做。」——把四张卡统一成"不做清单"、延续 hero 删词语法、每条有代码背书，但偏冷偏防御；最终采用宣示体版本。
- **配图来源**：卡 3（监护人授权邮件截图，mock-server 有模板）与卡 4（S5 对话）现在就有真素材；卡 1、卡 2 首发用设计稿，M1（X1 壳 + B 真链路）后换真界面。

### 7.7 图标海屏

- 产品内功能 icon 按顺序横向排列、**无缝浮动滚动**（接缝会露馅）、极慢。
- 顺序 = 学生的一天：计划 → 计时 → 记录 → 错题 → 知识点 → 复盘 → Chat → 收藏。
- **配文（已定）**：「**功能有很多，中心只有你。**」，「你」= `#4AD1FF`。（图标海是全景氛围不是功能罗列；配文负责把中心拉回"你"，否则这屏就变成功能介绍页。）

### 7.8 CTA + 页尾

- **末句英文**：「**Nothing, without you.**」→ 滑到页面最底部时变为「**You're everything.**」
- **布局硬要求**：滑到底时页面上部（该句 + 输入框）与页尾内容互不遮挡。
- **页尾下部**：一整块**与品牌色相近的流体渐变 abstract background，鲜明光感、有流动感、鼠标划过有交互**；其上分区：品牌 logo + 品牌一句话简介（暂填「围着你转的学习伙伴。」）+ **链接组**（隐私协议 / 服务条款 / 社区与文档 / 联系我们）+ **返回顶部** + 版权行。
- ⚠️ **占位规则（Skyer 定）**：所有"需要真实内容才能写"的位置——**联系方式、协议链接地址、社区与文档入口、备案信息、版权年份**——**结构留位、内容留空**，上线前统一确认后填入。**不预先编造**（这是本文档唯一的"不许填"条款）。
- ⭐ **句子翻转与光变亮是同一个拍子**：滑到底 → 光全开 → 句子翻转。整页唯一可爆发情绪处，时机由访客自己滑出来。
- **明暗弧线**：Hero 深色（夜）→ 页尾亮色光场（光）＝ **从夜走到光**。
- ⚠️ **合规硬项**：页尾必须显著标注「**学生团队开发，未经专业法律审核**」（pilot 口径）。
- 英文两句建议**不加中文小字对照**（短句的力在短）。

## 8. 动效与交互

| 层 | 预算 | 约束 |
|---|---|---|
| **落地页/页尾** | 放开：粒子、光效、流体渐变、3D 均可（页尾要求"鲜明"） | 四条工程约束（见下） |
| **产品内界面** | 克制：微交互、按钮光效、流式状态、轻微进入/完成反馈 | 不可用 hover-only 交互；不堆叠粒子/3D/强背景动效 |

- **手电只属于 Hero 的暗纹层**（机制是"让低对比线稿显形"），**不推广到全站**：卡片/截图场景用"展开"，不是"照亮"。
- **页尾流体渐变是全站唯一的"大面积 + 鲜明 + 强动效"特例**——依据 §4 的强度规则（该区域无正文要读）。
- **特效必须叙事化**：每个动效都要能回答"它在讲什么"；答不上来的就是装饰，装饰最容易滑向宇宙感。
- **四条工程约束**（重依赖场景必守）：① 路由级代码分割，重依赖只进落地页 chunk ② `prefers-reduced-motion` 降级 ③ 移动端简化或静态降级 ④ hero 重背景先静态、后渐进增强。

## 9. 技术现状与约束

| 项 | 现状 |
|---|---|
| 栈 | React 18.3 + Vite 5.4 + TS 5.6 + **antd 5.21** + CSS Modules；recharts / vis-network |

| 样式规模 | 35 个 CSS / 9577 行；49 个 jsx+tsx；响应式极少（约 15 处 `@media`） |
| 硬编码颜色 | 595 处 / 39 文件（tokens.css 83 + theme.ts 27 属源头，散落组件 **485 处**）——夜间模式漏网点 |
| token 现状 | `styles/tokens.css` 已有 69 个变量，语义名与旧"天空/云"名**混存**（`--bg-page`/`--ink` 与 `--bg-sky`/`--cloud`/`--glass-*` 并存）→ 重定时统一为语义命名 |

**React Bits**：官方**无独立 MCP**；路径是 `components.json` 注册 `@react-bits` registry + **shadcn MCP**（`npx shadcn@latest mcp`，配进 `~/.workbuddy/mcp.json` 并在连接器页点信任）。Registry 基于 React 19、我们 React 18 → 单组件需逐个验证。**变体选择**：Tailwind 引入后用 **`-TS-TW`**（TS + Tailwind）变体，与 beautifului 同一套。License **MIT + Commons Clause**（产品内可用，禁打包成组件库转售）。

**beautifului.dev**（MIT，`github.com/slev12397/beautiful-ui`）：产品内 AI 交互原语参考——Thinking / Streaming / **Approval** / Context / Recommendation / Prompt Bar。这套原语与 B 板块要做的组件**一一对应**：Approval ↔ 锚定确认卡（D17）、Streaming ↔ Chat 流式、Context ↔ 引用块。因此**Tailwind 的引入不是独立偏好，而是被"Chat 为核"的重构推着走的**。⚠️ 其 `SidebarNav` 用付费 `@central-icons-react`，不可照搬。
教训：DotGrid 这类背景实测拖 **GSAP 101KB gzip**，且无内置 reduced-motion/触屏替代 → 重背景必须路由分割。

**落地页特效可用组件（待实测）**：TextType（打字/删除，slogan 底座）、Aurora / ColorBends / Grainient / Balatro（流体渐变类，页尾候选）。
