## 0. 一句话结论

**有用，而且价值不在"内容"，在"红线"和"理论锚点"。**

这些 skill 的单位是**一节课**（lesson/stage），我们的单位是**一天/一周的学习状态**——流程不能照搬。
但里面有一批**措辞级的硬约束**，几乎逐字命中了我们品牌世界观里的
「**状态评估不是人格判定**」「**记录变化、不强迫进步**」——**这是外部权威（清华团队 + 文献引用）对我们产品哲学的独立印证**，
而且给的是可以直接写进 prompt 的句子。这是最高价值的部分。

**三层价值，按可用性排序**：

| 层 | 内容 | 可用性 |
|---|---|---|
| **1. 红线清单**（§2） | 12 条措辞级约束，跨 skill 汇总 | ⭐ 可直接进 prompt / 文案规范，**今天就可用** |
| **2. 交互规范**（§3） | `curriculum-planner` 的 Gate 1/Gate 2 追问与确认规范 | ⭐ 直接对应 D17 锚定确认卡与引导式追问 |
| **3. 理论锚点**（§4） | ZPD / UbD / 螺旋 / SEL / 费曼 各自对应我们的哪个功能 | ✅ 用于校准设计，不是照搬流程 |
| 4. 内容资产（§5） | 中国课标核心素养表（学科 × 学段）、数学学科设计 | 🔍 对知识点库元数据设计有参考，需产品侧判断 |

## 2. ⭐ 红线清单（最高价值，12 条）

以下全部是**跨 skill 汇总的原意转述**，括号内是出处。**这批措辞与我们现有品牌判断高度同频，建议直接进 Chat prompt 与文案规范。**

### A 组 · 「不判定」（直接对应「状态评估不是人格判定」）

1. **不凭标签判能力**：「不能以自称'初学者'、年级、一次错答或一道题的正确率直接判定能力」（ZPD）
2. **不写未说出的心理状态**：「不要把未说出的心理状态写成'你心里其实……'」（ZPD）
3. **不给用户贴理论标签**：「不把学习者定位为'正处于最近发展区'、'在最近发展区边缘'或已到达某个发展上限」（ZPD）
4. **不夸大单次结论**：「一次成功可支持'这道题在没有步骤提示时完成了'；**不能直接推出稳定掌握、长期保持或一般发展水平**」（ZPD）
5. **不预填未发生的事**：「未发生的尝试保持待完成；**无回应时不预填成功、误解或进步**」（ZPD）
6. **区分独立与受助**：「'两边该加还是减'这类指向步骤的问题**本身也是支持**；学习者在这种问题后自己写出答案，应记录为『在步骤提示后完成』——只有没有该类关键提示的新任务才记录为独立尝试」（ZPD）

> **这 6 条几乎可以逐条映射到我们的状态评估与复盘**：状态分不是人格判定、记录不预填、掌握度区分「独立完成 / 有提示完成」。
> 特别是第 4、6 条——**它们给出了"不夸大"的具体粒度**，这正是我们"温和的同行者"最难写对的地方。

### B 组 · 「不施压、不病理化」（直接对应「不强迫进步」与社区不做排名）

7. **不心理诊断、不病理化**：「不进行心理诊断，**不把学习挫折病理化**，**不以羞辱、公开排名或同伴压力驱动参与**」（SEL）
8. **不强迫暴露隐私**：「情绪表达被接纳且不被评判；**不要强迫学生公开个人创伤、心理状况或隐私经历**」（SEL）
9. **不承诺万能**：「**不承诺'万能学习法'**；需要比较研究证据时先核实来源」（learning-to-learn）

> 第 7 条**直接约束我们的社区 L1–L4**（我们已决定不做社交/排名——这条给了外部依据），也约束状态页的措辞。
> 第 8 条与我们「具体事件不进画像」是同一条边界，措辞可复用。

### C 组 · 「内部语言不得外泄」（直接对应我们的文案规范）

10. **规划标签不进用户可见文案**：内部框架词（`学习缝`/`元认知`/`平行目标`/`概念脊柱`/`费曼循环`/`复杂度升级` 等）**只用于规划与 brief，不作为学生可见的标题、标签或正文**（learning-to-learn / spiral / feynman 三处都有这条）
11. **用动作语言，不用术语**：
    - 检索练习 → 「**别急着翻，先把答案写出来**」
    - 自我解释 → 「**用自己的话给结论一个理由**」
    - 先预测后验证 → 「**先猜一下，再看对不对**」
    - 间隔复习 → 「**过几天再回来默一次**」
    - 监控理解 → 「**你是真的懂，还是只是感觉懂了？**」
    （learning-to-learn）
12. **标题写"发现/做出什么"，不写教科书目录**：用「拖动倾角，看射程怎么变」；**不用**「概念介绍」「知识讲解」「案例分析」「课堂总结」（k12）

> ⭐ 第 11 条**可以直接当我们的文案范例库**。这五句就是"温和的同行者"该说的话。
> 第 10 条对我们的提醒最具体：我们内部有「画像 / 归因 / 状态画像 / 掌握度」等一堆术语，**绝不能出现在学生看到的界面文案里**。

### 附：一条"学术诚实"的做法（值得我们学）

`zone-of-proximal-development/references/theory.md` 明确写：

> 「诊断尝试、支架和撤架是本 Skill 的**教学设计，不是维果茨基提出的一套固定步骤**」
> 「单次活动只能提供当前任务与支持条件下的表现线索，**不能测出稳定的'最近发展区分数'**」

并给出文献出处（Vygotsky 1978 / Wood-Bruner-Ross 1976 / Collins-Brown-Holum 1991），
并声明「本地验证能说明什么：产品行为证据 ≠ 真实学生效果」。

→ 我们面向中学生 + 家长 + 学校，**"我们的状态分是什么、不是什么"这句话迟早要对外说**。
这份文档的**表述结构**可以直接当模板：先给依据，再划清"我们做了什么是设计选择"，最后声明能力边界。

## 3. ⭐ 交互规范：`curriculum-planner` 的 Gate 1 / Gate 2

这个 skill 解决的是"多节课的系列规划"，但它对**提问与确认**的规范极其严苛，
**直接对应我们的 D17 锚定确认卡与引导式追问**：

| 规范 | 原文要点 |
|---|---|
| **问题必须是工具调用，不是散文** | 「The question IS the tool call, never the text」；**叙述里不得出现问号**，不得预览即将问的问题；把问题写进对话散文 = 用户拿不到作答表单 = 这个门失败 |
| **一轮一个调用** | 同一轮要问的全部内容放进**一次** `ask_user`；连续两次调用 = 两次等待，第二张卡落在还在读第一张的用户身上 |
| **2–3 轮，不是 4 轮** | 「填充式提问读起来像拖延，不像用心」；下一轮没有承重问题就进确认门 |
| **每轮开头要说你从上一轮拿走了什么** | 「用户必须看到自己的回答被使用」——这是一轮读起来专业而非缓慢的**全部原因** |
| **绝不问你已经知道的事** | 能安全默认的**陈述为你的决定让用户否决**：「默认中文讲授、每课 30 分钟，要改直接说」——不花任何一轮 |
| **选项里放例子，不放抽象档位** | 「完全零基础，没写过一行代码」而不是「初级」（后者让人猜） |
| **确认门（Gate 2）单独一轮** | 先展示完整计划 → 再 `ask_user` 要明确同意；**沉默或含糊的回答不等于同意** |
| **未确认不得开工** | 「架构未确认前不要创建」；用户改了就要重出清单再问一次 |

→ **建议动作**：这 8 条里至少 5 条（工具调用式提问、一轮一调用、2–3 轮上限、
"从上一轮拿走了什么"、默认陈述而非提问）**现在就该写进 D17 锚定确认卡与引导式追问的设计**，
它们是**交互规范**而非教学法，与我们的产品形态无关地成立。

## 4. 理论锚点：每个教学法对应我们的哪个功能

| 教学法 | 核心主张 | 对应我们的 | 怎么用 |
|---|---|---|---|
| **ZPD**（最近发展区） | 独立诊断 → 针对性支持 → **撤去支持再独立尝试** → 留下最小记录 | **状态评估 + 难度适配 + 掌握度** | 这个循环**就是我们的闭环**。可直接借它的"支持四档"表（没注意关键条件/步骤过多/知识缺失/受挫 → 各自的支持与学习者仍需完成的动作） |
| **UbD**（逆向设计） | 先定**持久理解**与**基本问题** → 再定**评估证据** → 最后设计经历（WHERETO） | **目标树** | 提醒：目标树不该是任务清单，应先问"你要建立什么理解、怎么证明"。与我们"目标=前方里程碑"一致，但更强调**评估证据先行** |
| **螺旋课程** | ⭐ **Revisit ≠ Review**：每次重访必须在 6 个维度之一升阶（复杂度/抽象度/关系密度/表征/迁移距离/边界反例） | **题本 + 艾宾浩斯复习** | ⚠️ **这是最尖锐的一条**：我们现在把题本做成"复习队列"，而它指出**同一道题回来时必须"多了什么"，否则只是重复**。它的「假螺旋检查」6 项可**直接当复习功能的验收标准** |
| **SEL** | 情绪觉察 / 自我管理 / 同理 / 协作 / 负责任决策 | **状态画像（情绪基线）+ 社区不做排名** | 借它的四条红线（见 §2 B 组）；它的"受挫—反馈—重试路径，失败不能是死路"也是我们建议语气的原则 |
| **费曼学习法** | 先讲给外行听 → 找**最小卡点** → 苏格拉底追问补因果链 → 再讲一遍 → 去术语 → 拆类比 → 换情境 → 合成记录 | **讲解 / 复盘 / 错因归因** | 它的「最小学习记录」7 要素可当**复盘卡模板**：我能解释什么 / 一开始怎样理解 / 卡在哪 / 新版解释 / 类比及失效点 / 能解决的新问题 / 仍不能解释什么 + 下轮目标 |
| **learning-to-learn** | 检索练习、自我解释、先预测后验证、间隔复习、监控理解、生产性失败 | **Chat 的"平行目标"** | 它的核心手法是"**把学习策略作为平行目标嵌进概念课**"——对应我们：建议卡不只说"学什么"，还要让学生**实际做一次主动回忆/自我解释** |

### ⚠️ 一个不适用点，但值得当问题提出

这些教学法大量依赖**多智能体 roster**：老师 + **学生代理**（"呈现'感觉懂了但默不出来'的真实状态"）+ 错误概念代理。

我们只有一个"同行者"。**要不要一个"和你一样的同学"角色？**
——它能承担"暴露真实状态"和"允许学生判断/修正"的功能，且比"AI 老师"更贴近我们"温和同行者"的定位。
**这是问题，不是结论**，留给产品侧判断。

## 5. 内容资产：中国课标核心素养表

`k12-core-literacy-planning/references/core-literacy.md` 给出了**按学科 × 学段的核心素养维度表**，覆盖：

- 语文（义务教育 / 高中两套措辞）、英语/日/俄、数学（义务教育"三会" + 高中六素养）
- 道德与法治 / 思想政治、历史、地理、科学、物理、化学（义务教育 / 高中两套）、生物（两套）
- 信息技术、艺术、体育与健康、劳动

**数学的两个细节**（对我们最相关，因为知识点库现在只有数学）：

- 义务教育数学 = **"三会"**（会用数学的眼光观察/思维思考/语言表达现实世界）+ 学段表现：
  - 小学：数感、量感、符号意识、运算能力、几何直观、空间观念、推理意识、数据意识、模型意识、应用意识、创新意识
  - 初中：抽象能力、运算能力、几何直观、空间观念、推理能力、数据观念、模型观念、应用意识、创新意识
- 高中：数学抽象、逻辑推理、数学建模、直观想象、数学运算、数据分析

**学段适配原则**（原文）：

> 小学偏**具象操作、体验与短语言**；初中偏**概念、证据与显式推理**；高中偏**系统、模型、多源材料与有价值判断**

→ 这三条**可以直接用于我们的建议语气与任务粒度**（同一个功能，初中生和高中生看到的措辞与任务大小应当不同）。
→ 课标表本身对**知识点库的学科/学段元数据设计**有参考价值，但要不要把"核心素养"做进数据模型是**产品决策**，本文不结论。

## 6. 建议动作

1. **立刻可用（零成本）**：把 §2 的 **A 组 6 条 + C 组 3 条**整理成 Chat prompt 的约束块与文案规范。
   这批措辞是我们"状态评估不是人格判定"的**外部印证 + 现成句子**，越早进 prompt 越好。
2. **进设计文档**：把 §3 的 5 条提问规范写进 **D17 锚定确认卡**与引导式追问的设计（与教学法无关地成立）。
3. **进验收标准**：把螺旋的「**假螺旋检查**」6 项，作为**题本复习功能**的验收项之一
   （Repeated not spiraled / Vocabulary inflation / Linear curriculum / Review curriculum / Context repetition / Difficulty escalation without conceptual deepening）。
4. **复用模板**：费曼的「最小学习记录」7 要素 → 复盘卡内容模板；
   `theory.md` 的"依据 → 设计选择 → 能力边界"表述结构 → 我们对外的状态分说明。
5. **待产品判断**：要不要"同学代理"角色；要不要把核心素养做进知识点库元数据。
