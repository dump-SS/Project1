04

M1 契约差异

转正 openapi.yaml 时必须落实的形态变更。

接口目标形态
GET /community/aggregate 移除 subject 参数；新增 stage（必填，junior / senior）；period 语义固化为当前 ISO 周、不作为查询参数；metric 枚举固化为 hours / focus / fatigue / completion。
同上 · 响应体 满足 k 时返回 { poolSize, percentiles, histogram }；不满足时返回 COMMUNITY_INSUFFICIENT_POOL，响应体不含任何数值。
POST /community/features 语义由「匿名特征值上传」改为「当周参与确认」，请求体不含任何特征值。决议 04 后需进一步重定义 — 自动参与下不再有每周确认动作，建议改由服务端按授权状态自动纳入
GET / PUT
/me/community-consent		 形态不变（{ enabled, updatedAt }）。补监护人授权失效联动语义与错误码：监护人授权撤销时，本开关一并关闭。
单位约定：completion 服务端存 0–1 比例、前端乘 100 展示为百分数（演示页现用 0–100，转正时重写）；hours 单位为小时；focus / fatigue 为 1–5 整数。
05

术语

附加说明，供实现与验收对照。

聚合格
按「指标 × 学段」切出的小群体。例如「初中生 × 周学习时长」是一个格，系统只统计这个格里的分布，不针对任何人。
k 值（最小群体规模）
格内人数低于 k 就整体不展示。人越少，越容易从统计结果里猜出某个具体的人是谁。
分桶
把连续数值归入区间，只公布每个区间的人数。不公布「某人每周学 17.5 小时」，只公布「12–16 小时区间有 6 人」。
桶计数下限
某个区间只有 1–2 人时，知道内情的人能对号入座，所以要与相邻区间合并后再公布。
分位数
p50 即中位数：一半人低于这个值。页面上的「我的位置」是拿自己的值和 p25 / p50 / p75 对比画出来的。
差分隐私
在统计结果里加入受控的随机噪声，使「多一人或少一人」对结果的影响可忽略。第一版不引入，代码已预留开关。
侧信道
不从数据本身、而从「数据变化的时机」泄露信息。聚合结果突然消失，旁观者可推断「刚才有人退出了」——延迟重算就是为了让变化时机不可观察。
物化表
预先算好存起来的聚合结果。查询接口只读这张表、不做实时计算，从根上杜绝用特殊查询条件拼出个体信息。
匿名参与 ID / salt
用服务器密钥（salt）把用户 ID 变成不可逆的乱码 ID。聚合流程只见到乱码，见不到真实账号；密钥定期更换，旧乱码无法被追溯关联。
poolSize
聚合池总人数（一个数字，不含任何个体信息）。满 20 时随结果返回；不满时接口只报「人数不足」，不返回具体数字，防止被算出「还差几人」。
