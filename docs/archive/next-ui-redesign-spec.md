### 1.2 逐页交互与展示功能

#### A. 登录 / 注册 / 找回密码（`/login` `/register` `/forgot-password`）

- 交互：邮箱 + 密码表单、提交、错误提示；登录成功后带回原目标路径（无则去 `/study-guide`）。
- 展示：品牌视觉，独立配色（未使用 antd），与业务页视觉体系不统一。

#### B. 导学计划 `/study-guide`（登录后起始页）

来源：`pages/StudyGuide/index.jsx` + `hooks/usePlanFlow.js` + `StudyPlanEditor/{StudyEditor,EnterButton,TaskList}.jsx`。

- 展示：页面标题「导学计划 / Study Guide」；**学习内容推荐块**（`fetchRecommendationContent()`，LLM 驱动，PRD 5.3），展示「学科 · 主题」+ 推荐理由；不满足条件时展示原因（如数据不足）。
- 交互：
  - **`AUTO 自动填充`按钮**：调 `generate({minMinutes:60})` 生成计划，首条任务「学科 · 主题」回填任务框。
  - **学习任务设置**（受控文本框 `StudyEditor`）。
  - **学习时间设置**（数字框，校验 10-600 整数 `MINUTES_VALIDATOR`）。
  - **任务列表 `TaskList`**：优先级 P1/P2、学科中文、主题、预计时长、状态标签；每行「完成」走 `PATCH /plans/{planId}/tasks/{taskId}`，行内错误 5s 自动清。
  - **`进入 / ENTER` 按钮**：未生成先生成（缺分钟/失败拦截），已生成携带 `{availableMinutes, task, planId}` 跳 `/study-timer`。
- 数据流：挂载查当日计划回填；`usePlanFlow` 管 7 state + 3 handler；离线可取上次成功计划（`offlineNote`）。

#### C. 专注计时 `/study-timer`

来源：`pages/StudyTimer/index.jsx`。

- 展示：番茄钟大盘（`EpochX` 品牌字）、专注/休息倒计时。
- 交互：专注/休息切换；专注时长（0-180）/休息时长（0-60）可编辑（`DurationField`，失焦或 Enter 提交）；开始/暂停/继续/重新开始；**任务完成自评弹窗 `SelfAssessment`**（PRD 5.2，10 秒内）：完成情况、专注度 1-5、疲劳度 1-5、情绪、难度，提交走 `createLearningRecord`；今日计划完成计数；完成后拉即时建议 `getRecommendation` 并可反馈（有用/一般/没用，`putRecommendationFeedback`）。

#### D. 个人数据 `/personal-data`

## 2. 起始页中央元素：结论与依据

### 2.1 结论

**登录后起始页（`/study-guide`）的中央元素，应是「今日导学计划」这一控件组——即"设定今天可学多久 → 一键生成/自动填充今日计划 → 得到可执行任务列表 → 进入专注执行"的主动作卡。**

- 中央主控件：**今日计划生成器**（可用时间输入 + `AUTO 自动填充` + 任务列表 + `进入 ENTER`）。
- 中央伴随信息：**当前状态标签 + 一句 LLM 学习内容推荐**（只读呈现，作为"为什么今天这样安排"的解释锚点）。

这套组合已在现有代码里齐备（`usePlanFlow` + `StudyEditor` + `TaskList` + `EnterButton` + `fetchRecommendationContent`），本次**不新增功能**，只把它从"竖直堆叠的表单"重排为"以计划为中心、大留白、空气感"的主动作区。

### 2.2 依据（对比 PRD）

- **PRD 5.1**：学生打开产品能在 1-2 分钟内获得"今天该学什么、怎么学、学多久"的可执行规划，而不是空白页面发呆 → 起始页中央必须是"生成并拿到今日计划"的动作。
- **PRD 1 / 2 闭环**：把「学习规划 - 状态感知 - 个性化建议」串成闭环。起始页是入口环（规划），下游是执行→状态→建议→复盘→回到规划，中央承载入口。
- **PRD 5.1 交互要点**：计划可手动调整、完成情况需确认 → 对应 `TaskList` 完成按钮与 `StudyEditor` 编辑。
- **PRD 5.2/5.3/8.3**：冷启动套模板、有数据按状态调整、LLM 内容推荐作解释 → 状态标签 + 推荐理由作为计划的解释性副信息并列展示。

### 2.3 中央元素优先级

| 层级 | 元素 | 依据 |
|---|---|---|
| 主（C 位，最大视觉权重） | 今日可用时间 + 生成/自动填充 + 任务列表 + 进入按钮 | PRD 5.1 |
| 次（主控件上方，解释锚点） | 当前状态标签 + 一句内容推荐及理由 | PRD 5.2/5.3/8.3 |
| 辅（弱化次级入口） | 「看数据 / 复盘 / 建议 / 目标」跳转 | 闭环后继节点 |

## 3. 视觉语言：人文风 · 空气感（本次核心）

### 3.1 情绪板（从 6 张参考图提炼）

参考图共性：**通透的天空/云/海摄影**、**大面积留白与呼吸感**、**衬线大标题 + 细体/斜体副标**、**磨砂玻璃信息块**、**极细分隔线与星点装饰**、**低饱和的蓝—云白—暖金过渡**。

一句话方向：**"像抬头看天"——克制、通透、有温度**。视觉服务于 PRD 4.1/6.3 面向未成年人的关怀语气：不制造焦虑、不用刺眼强对比，用空气感传递"和自己的节奏和解"。

五个可执行关键词：

1. **空气感**：大留白、低密度信息、元素之间留出天空般的空隙。
2. **通透**：背景是柔和的天空渐变；卡片是磨砂玻璃（半透，可见背景光晕），不是实心硬卡。
3. **衬线人文**：标题用衬线（serif），带古典书卷气；数字/大标题可用衬线撑起仪式感。
4. **细体正文**：正文用无衬线细体（weight 300-400），关键处适当加粗（500-600）形成层次，而非全篇常规粗细。
5. **微光**：光晕、渐隐、缓慢过渡；装饰用极细线、四角星点（✦）、竖排小字。

### 3.2 色彩令牌（替换 v0.1 的浅蓝实心方案）

以"天空一日"为色轴：白昼天蓝 → 云白 → 黄昏暖金 →（深色语境）夜蓝。**低饱和、高明度、柔过渡**。

```
/* 背景与天空渐变 */
--sky-hi:        #A9D4EC   /* 天空上部·主蓝 */
--sky-lo:        #DCEBF5   /* 天空下部·近地雾蓝 */
--cloud:         #F4F9FD   /* 云白·页面基底/卡片近白 */
--dusk-warm:     #F3E4CE   /* 黄昏暖金·点缀/进度暖色 */
--night-blue:    #35507F   /* 夜蓝·深色区/强调文字 */

/* 文字 */
--ink:           #2B3A55   /* 主文·深靛蓝（非纯黑，带空气感）*/
--ink-soft:      #5C6E88   /* 次文·冷灰蓝 */
--ink-faint:     #93A6BE   /* 辅助/占位·雾灰蓝 */
--on-photo:      #FFFFFF   /* 压在摄影/深色上的白字 */

/* 主色与语义 */
--primary:       #6FA8D6   /* 主色·晴空蓝（按钮描边/选中/链接）*/
--primary-deep:  #4A7CB0   /* 主色深·hover/强调 */
--success:       #8FD3B6   /* 正向·薄荷 */
--warning:       #EBC48B   /* 提醒·暖沙（不用刺眼橙红）*/
--danger-soft:   #D89B9B   /* 危险柔·撤销/删除，克制使用 */

/* 玻璃与线 */
--glass-fill:    rgba(255,255,255,0.42)  /* 磨砂玻璃填充 */
--glass-stroke:  rgba(255,255,255,0.60)  /* 玻璃描边（1px）*/
--hairline:      rgba(43,58,85,0.14)     /* 极细分隔线 */
```

- 状态标签映射（PRD 5.2 `StateLabel`）：高效稳定=`success`、波动上升期=`primary`、疲劳预警=`warning`、情绪受阻=`danger-soft`、数据不足=`ink-faint`。均为低饱和，避免"体检报告式"红黄警示。
- 学科色沿用 `subjectColors`，但整体降饱和以融入空气感（可在 theme 里加一层 `opacity`/柔化，不改 key）。

### 3.3 字体系统（标题衬线 · 正文细体加粗）

```
--font-serif:  "Noto Serif SC", "Songti SC", Georgia, "Times New Roman", serif;   /* 标题/大数字/引言 */
--font-sans:   "Inter", "PingFang SC", "HarmonyOS Sans", system-ui, sans-serif;    /* 正文/控件/表单 */
```

- **标题**：`--font-serif`，字重 500-600，字距略收（`letter-spacing: -0.01em`）。英文副标可用衬线斜体（呼应参考图 `exhale stress.` / `Breathing Techniques`）。
- **正文**：`--font-sans`，字重 **350-400（细体）**为基调；强调值（今日时长、完成数、当前状态标签）用 **500-600 加粗**制造层次。
- **大数字/仪式感**（倒计时、今日累计）：`--font-serif`，字重 400，字号大、行高松。
- 中英混排：中文标题衬线 + 英文小字衬线斜体做点缀；正文中英统一无衬线细体。

字阶（rem，1rem=16px）：

| 用途 | 字号 | 字重 | 字体 |
|---|---|---|---|
| Hero 大标题 | 2.75–3.5 | 500 | serif |
| 页标题 | 1.75 | 500 | serif |
| 区块标题 | 1.25 | 500 | serif |
| 大数字/倒计时 | 3.0 | 400 | serif |
| 正文 | 0.95 | 350–400 | sans |
| 强调正文 | 0.95 | 550 | sans |
| 说明/竖排小字 | 0.75 | 400 | sans，字距 +0.08em |

### 3.4 卡片 = 磨砂玻璃（替换实心卡）

- 材质：`background: var(--glass-fill)` + `backdrop-filter: blur(16px) saturate(1.1)` + `1px solid var(--glass-stroke)`。
- 圆角：`20px`（大而柔）；阴影极轻：`0 8px 32px rgba(53,80,127,0.10)`，靠光晕而非投影分层。
- 卡片可透出背景天空渐变/光晕，形成"浮在天空上"的层次。
- 降级：不支持 `backdrop-filter` 时回退到 `rgba(255,255,255,0.82)` 半透实填，不破版。
- 内容密度低：卡片内边距 `28–32px`，行与行之间留白充足。

### 3.5 背景与氛围

- 页面基底：`linear-gradient(180deg, var(--sky-hi), var(--sky-lo) 60%, var(--cloud))` 的柔和天空渐变，随页面滚动缓慢视差（可选，尊重 reduced-motion）。
- 顶部/角落加一到两处**柔光晕**（径向渐变，低透明，缓慢飘移），呼应参考图的镜头光斑。
- 关键页（起始页、番茄钟）可用一张**低对比天空/云摄影**作 Hero 背景，压半透暗层保证文字可读；其余页用纯渐变即可，避免喧宾夺主。
- 装饰元素：极细竖线分隔、四角星点 ✦、竖排英文小字（如 `WEDNESDAY` / 日期），克制点缀，不堆砌。

### 3.6 按钮与控件

- 主按钮：**胶囊描边**为主（`1px solid var(--primary)`，透明/极浅填充，圆角 999），hover 时填充 `--primary` 反白——呼应参考图 `Explore mindfulness at your pace` 的细描边胶囊。
- 次按钮：文字按钮 + 下划线动效或箭头 `→`（呼应 `Box Breathing →`）。
- 输入框：无边框/仅底部 hairline，聚焦时底线渐变加深；标签中英双行（沿用 `StudyEditor` 风格但去掉硬框）。
- 选中/激活：用主色细下划线或柔光背景，不用实心块。

### 3.7 动效与过渡（空气感的关键）

- 时长令牌：`fast 160ms / base 280ms / slow 480ms`；缓动 `cubic-bezier(0.22,0.61,0.36,1)`（缓出，像飘）。
- 路由切换：淡入 + 10px 上浮（`slow`），像云飘入。
- 卡片入场：进入视口错峰淡入上浮（stagger 60ms）。
- 背景：光晕缓慢飘移（20–40s 循环）、天空渐变随滚动轻微视差。
- 计划生成：任务逐条淡入；番茄钟到点用一次柔和呼吸脉冲（缩放 1→1.03→1），不闪烁。
- 数字：今日时长/完成计数 280–480ms 计数滚动。
- **全局遵循 `prefers-reduced-motion`**：命中时禁用视差/飘移/位移，仅保留淡入。
- 禁止：强闪烁、硬切、刺眼红色告警、超过 480ms 的大位移。

### 3.8 无障碍

- 摄影/渐变背景上的文字必须压半透暗/亮层，保证对比度 ≥ WCAG AA。
- 磨砂玻璃上的正文用 `--ink`，不用浅灰，确保可读。
- 交互元素带 `aria-label`/`aria-busy`；键盘可达；动效遵循 reduced-motion。
- 注：完整 WCAG 合规需人工辅助技术测试与专家评审，此处只给工程基线。

## 5. 起始页（`/study-guide`）重设计细则

> 只重排呈现与动效，功能与 `usePlanFlow` 数据流不变。以"抬头看天"的空气感承载 PRD 5.1 的入口动作。

### 5.1 版式（自上而下）

1. **Hero 天空区**：柔和天空渐变（可叠低对比云摄影 + 半透暗层）。居中衬线大标题「今日导学 / Study Guide」，副标衬线斜体一句（如当前状态一句话 / 日期竖排小字 `WEDNESDAY · JUL 30`）。整体大留白，像壁纸。
2. **状态解释条**（次级，只读，磨砂玻璃细条）：当前状态标签（低饱和语义色）+ 一句 LLM 内容推荐及理由。数据不足显示"数据积累中"（PRD 5.2 冷启动），不出误导结论。
3. **今日计划主卡（C 位，磨砂玻璃大卡）**：
   - 可用时间输入（底线式，10-600 校验）。
   - `AUTO 自动填充` 与 `生成/进入` 作为清晰主 CTA 序列（胶囊描边主按钮）。
   - 生成后 `TaskList`：优先级、学科色点（降饱和）、主题、预计时长、状态、完成按钮；任务逐条淡入。
   - `进入 ENTER` 固定主卡底部主 CTA，跳 `/study-timer` 携带 `{availableMinutes, task, planId}`。
4. **辅入口区**（弱化）：看数据 / 复盘 / 建议 / 目标 的文字 + `→` 次级跳转。

### 5.2 交互细则

- 未填时间点"进入"：底线式输入下方细提示"请先填写 10-600 的可用学习分钟数"（沿用文案），不弹窗。
- 生成中：主按钮内联 spinner + 禁用防重复（沿用 `EnterButton` busy）。
- 离线取用上次计划：顶部磨砂玻璃轻提示"离线取用上次成功计划"（沿用 `offlineNote`）。
- 任务完成：行内乐观更新 + 失败行内红字（用 `danger-soft`）5s 自动清（沿用 `TaskList`）。
- 当日已有计划：挂载回填时间与首任务（沿用 `usePlanFlow` mount），主 CTA 文案切"进入"。

### 5.3 动效

- Hero 标题淡入 + 轻微上浮；背景光晕缓慢飘移。
- 主卡淡入上浮；任务列表逐条 stagger。
- 状态标签变化用颜色渐变过渡，不跳变（呼应 PRD 5.2"避免状态分跳变"）。

### 5.4 番茄钟页呼应

- 倒计时大数字用衬线；环形进度用主色→暖金渐变；到点柔和呼吸脉冲。
- 背景可用低对比天空摄影，专注时背景微微变暗聚焦，休息时回明——用氛围替代生硬提示。
