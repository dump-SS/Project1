TL;DR · 一分钟看懂

五句话讲完这次重构

1

一切从对话发起。首页就是 Chat，闲聊 / 建任务 / 搜题 / 讲知识点 / 复盘都从这里开始，不再逐页点导航。

2

个人中心 = 关于我的一切。数据、画像、档案、复盘记录、目标树详情、社区参照、收藏、设置全收进一个仓。

3

不做对话历史。你看不到往日对话原文，但模型记得关于你的一切——而且这份记忆可看、可改、可删。

4

学习记录是活实体。不是「提交即封存」，事后随时补正确率、补错题、改归因。

5

规则免费、AI 计费。让用户免费看「状态如何」，为「AI 告诉我怎么办」付费；群体只做参照、不做社交。

§0

Core shift

一句话核心转变

交互核心从「逐页点导航」变为「对话驱动 + 上下文栈」。

Chat = 行动与对话的起点

一切动作（闲聊 / 建任务 / 搜题 / 讲知识点 / 复盘）从对话发起。是主焦点、视觉中心。

个人中心 = 关于我的一切

数据、画像、档案、复盘记录、目标树详情、社区参照、收藏、设置。是「档案与资产的归宿」。

分工铁律：个人中心管「学习行为」，知识页管「知识掌握」；规则引擎管「事实」（免费），AI 管「表达」（计费）。

§1–2

Entry & Information architecture

入口与信息架构

双柱 + 少数独立页；导航视觉弱化。入口先解决「谁进来、第一天看到什么」。

§1.1 免登录 / 游客双轨
  • 不强制登录，游客可试用非 AI 功能
  • 游客态 AI 标灰虚化 + 小字引导，不能用 Chat
  • 登录/注册入口常驻身份区（点「游客 ?」展开）
  • 试用数据不接管，登录即清空，不额外弹确认
§1.2 首次体验
  • 登录 → 动画 A 进首页
  • 注册页有「暂不登录，先试试看」→ 动画 B 进游客态
  • 合法新用户首登走「激活式引导」：建档 + 个性化
§1.3 第一天体验
  • 新手任务软引导，首日顶替 Go on 组
  • 问候语「预设骨架 + 动态填充」混合
  • 渐进揭示：按需为主 + 演示卡为辅

信息架构全景

【入口】 登录 / 注册 / 游客(试用，非 AI 功能；登录入口常驻「游客 ?」) 【首页 = Chat】 主焦点 · 问候语 / 推荐卡 / 对话流(单线程·无历史) / 侧面板(视觉弱) 【独立页】 计划(guide) · 计时(全屏) · 个人中心 · 知识页(题本/考试) └─ 目标(goals) [已取消] 并入个人中心 【个人中心】 数据 / 画像 / 档案 / 复盘记录 / 目标树详情 / 社区参照 / 收藏 / 设置 └─ 设置 ─┬─ 账号与资料(建档 / 登出) └─ 授权与隐私(监护人授权 · AI 三开关 · 群体参照) 【侧面板】 搜题结果 / 任务卡 / 复盘 / 目标树简略
§3

Core interaction

核心交互逻辑

意图判定、上下文栈、专注计时、活实体记录、不做对话历史——这五件事定义了新产品的交互骨架。

3.1 意图判定 3.2 推荐卡 3.3 任务卡 & 上下文栈 3.4 计时 & 记录 3.5 搜题三态 3.6 不做对话历史 3.7 讲解分层 3.8 划选与随手问
3.1 意图判定三分类
意图触发
闲聊基于画像回应，适时提取信号写入画像
创建任务自然语言 → 任务卡；识别「预习/复习」请求
知识求助/搜题 解题 · /讲知识点 讲透 · /查 查概念

判定入口：斜杠命令 + 按钮 + 模型裸判，三者并存。注意：三分类是识别口径不是输出限制——主意图定基调，允许一次产出多产物（D53）。

3.2 首页推荐卡（三组 + 首日）

Go on（继续）

未完成计划 / 未回填正确率 / 待续复盘。存在未完成事项即硬性出现；划掉后 3 天不推。

推荐

状态 / 内容 / 目标规划三类合并，卡内 type 标注区分。需 AI + 足够数据，不足则整组空缺；7 天不重复。

洞察

群体洞察（L4），带「N 名匿名同龄人」标注。需聚合样本，克制出现；每周 ≤ 1 条。

卡片 = 展示层（display）+ 意图层（payload），点击注入结构化上下文而非拼字符串——精确、可追溯、可降级（无 AI 时规则模板兜底）。生成规则：触发 + 排序 + 去重指纹 + 冷却，宁缺毋滥。

3.3 任务卡 & 上下文栈

任务卡

  • 卡内可操作：勾选 / 改时 / 删
  • 双载体：对话流 + 侧面板
  • 切页顺承：未建完的任务信息带到创建页，给「是否保留」
  • 归属沿用计划（guide）与目标（goals）；目标为长期 → 短期父子树

上下文栈

  • 单会话 + 上下文栈，非多线程并行会话
  • 深度 3 · LIFO · 会话级；与「持久化中间态」拆层
  • 超限沉降：任务草稿 → Go on，搜题讲解 → 归档，闲聊 → 丢弃
  • 锚定确认卡：切回时基于栈顶接续，也是通用回溯交互
3.4 计时 & 学习记录

计时（专注态）

  • 全屏沉浸、不出现导航；可呼侧栏 Chat，但锁定为「知识求助」类
  • 双模式：倒计时（有目标时长）/ 正计时（不限时），服务端时间戳按 mode 分支恢复
  • 到点 软提醒，不强制结束；继续则平滑转正计时语义
  • 僵尸治理：超时失效 + 恢复裁决卡（不自动记账）+ 有效时长 ≠ 墙上时长
  • 只留「结束」一个出口，不做挂起

学习记录（活实体）

  • 记录可事后回写，不是「提交即封存」
  • 收尾三层：结束瞬间（0 步可走）/ 轻收尾卡（约 10 秒）/ 延后引导
  • 自评双轨：量化 → 引擎，叙事 → 画像，两者都留存
  • 数值来源 B 方案：完成度 / 情绪直填，专注疲劳难度口语转译
  • 正确率 / 错题三态可填（结束即填 / 延后补 / 永不填），数据层 nullable
  • 软字段缺失只「变粗」，不「变假」；核心也缺 → insufficient_data
3.5 搜题三态（知识求助 · 解题）

直给

完整解答一次给出，适合有储备、想快看的人。

解析式

逐项说明，卡片式；简单题退化为思路说明。

引导式

多轮交互教学循环，可中途打断发思路，模型判断后续接 / 纠正。

三态记忆 + 可切换；无论哪种模式，末尾统一输出知识点卡片。五阶段链路：输入识别 → 解题生成 → 解析呈现 → 知识关联（embedding）→ 沉淀回流。正确性降险：分步结构化 + 「AI 解题可能有误」明示，不过度依赖检索增强。

3.6 不做对话历史 差异化 · 正文 §3.8 / D45

你看不到往日的对话，但模型记得关于你的一切——而且这份记忆可看、可改、可删。无历史列表、无「新建对话」，全产品只有一条持续演进的对话。

通用 AIEpochX
记忆形态线性对话流水结构化沉淀（画像 / mastery / 记录 / 归档）
能否回看能，翻原文不能翻对话原文
能否修改不能能

配套三口径：① 会话 = 连续使用周期 + 不活跃老化（不按零点重置）② 翻篇靠意图切换 + 弱化的「清空当前上下文」，不设 New Chat ③ 对话原文短期留存（安全审计 + 危机追溯）、产品不可见、不入画像。
连带项：画像升格为信任基础设施（无历史的前提是画像可见可改）；知识页归档扩为「搜题 + 讲解」。

3.7 知识点讲解分层（/讲知识点）
层内容规模化
L1结构化文字讲解（分节 / 公式 / 例题 / 自测）可
L2结构化 + 轻交互（折叠 / 选择自测 / 表格着色）可
L3富交互仿真（Canvas / 滑块 / 动态判定）精品方向

L3 只做精选核心知识点，参数化模拟器模板，不逐点定制；双成本 = 技术 + 教学设计。另有呈现细则（D52）：回顾取原文 + 重讲现生成并存；多解法侧面板横向分页（上限 2–3，默认只生成主解）；语文 / 外语阅读题原文回溯；输出限中学阶段解法。

3.8 划选与随手问浮窗 D51

主路径：引用到主对话

划选内容作为引用带进主对话，完整走主意图判定与上下文栈。

旁路：随手问浮窗（受限 Chat）

单向继承上下文、仅基础问答、不递归、关闭即销毁、可拖动 / 挂起 / 添加到主对话（只带显式内容）。浮窗不入上下文栈，不影响主对话状态机。

§4

Feature re-mapping

功能从属关系

原有功能重新归位 + 三大板块 + 设置授权 + 收藏题本考试。

数据 / 复盘 / 建议 归位
原新归位
个人数据总览→ 个人中心
复盘→ 侧面板 + 个人中心「复盘记录」
建议→ 首页「推荐」组（三类）
目标树（父子从属）

长期目标下挂多个短期子目标，模型可拆解 / 规划。展示：侧面板 = 父子缩进列表；个人中心 = 树 + 时间线叠加（从属 + 节奏正交）。

用户画像

成绩 + 兴趣 / 性格 / 经历 / 归因 + 情绪基调。四分组（学习 / 状态 / 归因 / 兴趣与经历），按意图选组注入、不全量。模型隐式提取写入，用户可改可删、不可新建。生活域负面事件细节不进、情绪状态进。已摘掉合规暂缓（D50）。

知识页（七模块）

掌握度总览(薄弱域显式) / 知识点检索 / 知识点详情 / 错题本 / 搜题归档 / 知识图谱 / 难度双层模型（官方 + 个人覆写免审核 + 众包）。

社区（L1–L4）

横向坐标 + 群体智慧引擎，不做社交。L1 你在哪 / L2 趋势 vs 同龄人 / L3 相似人群（按维度不按人）/ L4 融进建议。L3 特色：偏离预警 + 前瞻轨迹 + 难度共识。

情绪安全（L1/L2/L3）

学习助手 ≠ 心理医生。日常负面 → 共情；强烈负面 → 倾听 + 提议求助；明确危机 → 接 CRISIS_RESPONSE 转介。属安全底线，不随合规暂缓跳过。

设置 · 授权 · 通知 归位 v0.26 新增 · 正文 §4.7
项结论
监护人授权设置 →「授权与隐私」子页；<14 岁建档强制门槛；入口两处、页面一处。属设计底线，不随合规暂缓

收藏 · 题本 · 划选 · 考试 v0.28 新增 · 正文 §3.9 / §4.8 / §4.9
项结论
收藏任意模型输出可收藏（含非课内知识、图片圈选）；存快照不存引用（否则原文到期变死链）；不进知识点库、不参与 mastery；内容不可编辑但支持高亮与「虚化」自测；反复收藏覆盖并轻提示；导出二期
归位题本 + 知识点记录 → 知识页（可评测）；chat 收藏 → 个人中心（不可评测）。内置分组是筛选维度，自定义分组是标签，两者正交
题本错题本升格：两正交维度（错因 + 意图），mastery 只消费「有错因」的。添加原则 明示 → 直加、推断 → 确认；返考淡化「组卷」措辞叫「复习 / 小测」
划选两条路径：引用到主对话（主）+ 随手问浮窗（受限 Chat：单向继承、仅基础问答、不递归、关闭即销毁、可挂起）
考试Exam 为独立实体，Goal 引用（examId + targetScore）；错题可标来源考试；成绩回填是唯一能把自评与客观结果对上的数据
上传Chat 可随意上传（照片入闲聊 / 作业单直接生成计划）；限页数与大小、仅会话内有效、不落库；生成的要点摘要可进收藏（走 privacy_filter）
学科工具 · 计算器 · 题目排序 v0.29 新增 · 正文 §4.10
项结论
入口任意页面悬停上边界 → 黑条滑出 → 单击下拉；菜单占满上部、左右抵边，把下方内容挤下去
卡片首卡 = 彩色学科卡（斜置学科图标）：hover 浮动放大 + 背景模糊 + 展开全部学科，单击即切换学科与工具集；后随深灰工具卡（略宽）
工具浮窗单击学科卡 → 卡片居中扩大、顶栏收起、页面恢复，以类浮窗对话形态打开
科学计算器pilot 唯一工具，其余占位「开发中」。右上「添加到对话」→ 切对话页、变输入框引用块「科学计算器 ✕」；注入本次全部计算输入输出，未按「=」的最后一条也要归拢
/题目排序首次拍照后「+」光效引导（仅首次）。四选项：难易 / 掌握度 / 自定义提示词 / 价值遴选（按知识点与解法交叉度排刷题价值）；适用一页多题
阶段口径pilot 为删档测试（可清库、schema 可激进、不做导出迁移）；beta 起不删档。三层身份：users.id 永不变（外键）/ email 可改（仅登录凭证）/ handle 可改（对外）——在 pilot 期间就解耦

原因

Q合规和隐私这次到底什么状态？+

仍是底线

情绪安全 L3 危机响应（接 safety_filter + CRISIS_RESPONSE）、监护人授权（<14 岁建档强制门槛）属设计 / 安全底线，不随暂缓跳过。仍挂「上线前补」的：未成年付费、危机响应 prompt 基线、协议条款。所有社区聚合匿名 + 最小群体 k = 20。

Q别的 AI 都有历史记录，为什么我们反而不做？+

这是产品最核心的一个差异化赌注（D45）。逻辑是：通用 AI 的记忆形态是「线性对话流水」，回看靠翻原文、修改做不到；我们把它换成结构化沉淀——画像、mastery、学习记录、归档。

代价与补偿

用户失去「翻原文」的能力，换来三样东西：记忆可看可改可删（信任基础设施）、上下文永远干净（不被三个月前的闲聊污染）、以及对话原文只在短期内留存用于安全审计与危机追溯、产品不可见、不入画像。会话也不按零点重置，而是「连续使用周期 + 不活跃老化」；翻篇靠意图切换 + 弱化的「清空当前上下文」。

对应决策：D45 不做对话历史 · D50 画像四分组 · D36 上下文栈 · §3.6

B 组

复杂真实场景，规划里怎么接

21 个场景

这些不是假想敌——每一条都是「用户真的会这么用」时必然会撞上的坑。

对话与记忆

场聊到一半突然要搜题，搜完还想接着刚才的话题聊+

单会话模型最典型的冲突：一个会话里同时存在两条「聊到一半」的线。

解法

上下文栈按 LIFO（后进先出）处理：搜题作为栈顶新分支压栈，搜完切回时栈顶优先接续刚才的闲聊，模型记得聊到哪了。深度上限 3，日常完全够用。

D02 单对话 + 上下文栈 · D36 深度 3 / LIFO / 会话级

场同时挂着好几件没聊完的事，又想开第四件+

栈深度 = 3，第四件事进来必然挤掉一个旧的。关键是「挤掉」不等于「丢」。

解法

最旧者按类型沉降：任务草稿 → 转持久化中间态，进首页「Go on」组继续可见；搜题 / 讲解到一半 → 转知识页归档，可重新发起；纯闲聊中断 → 直接丢弃。各自带 TTL，任务草稿 7 天不碰就归档提示。

D36 超限按类型沉降 · D21 Go on 组 · D47 知识页归档

场用了一个月，想翻回上周那次讲得特别好的讲解+

不做对话历史（D45）之后，这是用户最直接的不便。

解法

三条补偿路径：① 收藏——当时觉得好就该收藏，存的是快照，不会因为原文到期变死链（D46）；② 知识页归档——搜题和讲解的记录都归档，可重新发起（D47）；③ 重讲现生成——讲解支持「回顾取原文 + 重讲现生成」并存，重生成保证不了一致性，所以两条路都在（D52）。

D45 不做历史 · D46 收藏存快照 · D47 归档 · D52 回顾与重讲并存

场每天零点会话会不会清空？隔一周再来说的话它还认识我吗？+

「单会话」很容易被误解成「每天重开一条」。

解法

会话 = 连续使用周期 + 不活跃老化，不按零点重置。隔一周回来，长期记忆靠结构化沉淀（画像 / mastery / 记录）兜底；跨登录周期的话题则通过摘要注入问候语衔接——这正是问候语「预设骨架 + 动态填充」的数据源。

D45 会话口径 · D53 跨登录话题摘要注入 · D40 问候语混合填充

场过了两天想起来，说「上次那份数学卷」想补个正确率+

模糊指代 + 跨天回溯，模型很容易补错对象。

解法

四步锚定回溯：① 识别为「对历史记录的事后补充」→ ② 拉出近期计划 / 记录候选 → ③ 弹锚定确认卡「是周三 20:00 数学计划那条吗？［就这条 / 换一个］」→ ④ 确认后回写并联动（正确率补记 · 错误点 → 题本 · 归因 → 画像）。锚定确认卡是通用能力，补错题、报目标进度都复用。

D16 学习记录是活实体 · D17 锚定确认卡 · D15 正确率可事后补

场任务在对话里建到一半，用户直接跑去计划创建页了+

对话里说的信息和表单页要填的字段是两套表达，直接跳走会丢上下文。

解法

切页顺承：已抽取的任务信息（学科 / 主题 / 时间 / 目标）随跳转预填到创建页，并给「是否保留」选项——一键采纳或清空重来。

D04 任务卡双载体 + 切页顺承

场模型把一句闲聊听成了「建任务」，或者一次只肯干一件事+

纯靠模型判断意图必然误判；另外三分类容易被误读成「一次只能输出一种东西」。

解法

两道保险：① 意图入口三路并存——斜杠命令、按钮、「+」菜单里的快捷动作与自定义常用语，判错时用户一键纠正；② 三分类是识别口径不是输出限制——主意图定基调 + 允许多产物（比如闲聊里顺带建了任务卡）。学习困境场景的原则是「先当人，再当助手」，不主动推销功能。

D03 三入口并存 · D53 识别口径 ≠ 输出限制 · D23 自定义常用语

场划选了一段看不懂的定义，只想快速问一句，不想打断主对话+

如果每次划选都塞进主对话，主对话的上下文栈很快就被污染。

解法

两条路径：主路径引用到主对话；旁路随手问浮窗——受限 Chat：单向继承上下文、仅基础问答、不递归、关闭即销毁、可拖动 / 挂起 / 添加到主对话且只带显式内容。浮窗不入上下文栈，不影响主对话状态机。

D51 划选两路径

场拍了一张作业单，想直接变成今晚的计划+

文件上传既是高频需求，也是隐私与存储成本的来源。

解法

Chat 可随意上传：照片入闲聊 / 作业单直接生成计划。约束是限页数与大小、仅会话内有效、不落库；生成的要点摘要可以进收藏（走 privacy_filter）。图片 / 图表内的圈选追问记为开放问题（多模态坐标定位精度一般）。

D55 上传文件 · §6 开放问题

计时与专注

场正专注计时，卡在一道题上想查，又怕被打断+
解法

可呼出 Chat 侧栏，但侧栏被锁定为「知识求助」类——只能搜题 / 讲知识点 / 查，闲聊和建任务不可用。原则是「专注中只允许为眼前这道题服务」。这次求助是临时会话，但会自动归档。

D05 全屏专注页 + 侧栏锁定知识求助

场倒计时到点了，但用户还想继续学+
解法

到点走软提醒，不自动结束。可结束（时长封顶 target），或继续——继续则平滑转入正计时语义持续累积，最终时长 = target + 续学时长。续学部分若被放任不管，走正计时的僵尸治理兜底。

D32 到点软提醒 · D30 计时双模式

场用户直接杀掉 App / 忘了结束，三天后才回来+

最脏的场景：留下一个「进行中」的计时，墙上时间已过 70 小时。

解法

三层治理：① 服务端一直持久化 started_at + 模式 + 目标时长，前端只是视图；② 超时失效——倒计时到点后时长封顶 target，正计时累计超上限（如 > 6h）判异常截断；③ 回来弹恢复裁决卡「已计 X 分钟 · [保留按 X 记] [丢弃] [手动改时长]」，绝不自动记账。有效时长 ≠ 墙上时长。

D31 僵尸计时治理 · D30 服务端按 mode 分支恢复

学习记录、画像与知识资产

场收尾时用户只丢了一句「还行吧」+
解法

宁缺毋滥，静默降级：语义模糊就留空，不硬猜；能提部分就只采部分；低置信度只采高置信字段；AI 不可用则静默 null。状态引擎这边——核心自评（完成度 + 情绪，直填）在 → 正常算分，软字段缺则跳过、按可用部分归一化；核心也缺 → 降级 insufficient_data。

D34 口语转译兜底 · D20 数值来源 B 方案

场用户就是懒得回填正确率和错题+
解法

三态都可接受：结束即填 / 延后补（走锚定回溯）/ 永不填。数据层全部 nullable，状态引擎、mastery（MIN_SAMPLES 置信度规则）、画像归因提取都容忍缺失——不报错、不假造、不因缺失扭曲结果。正确率偏当场填，错题偏延后整理进题本。

D15 正确率可事后补 · D20 三态 nullable · D48 题本添加原则

场系统自动把一道题加进了题本，但用户觉得它没做错+

题本从「错题本」升格后，什么都往里塞会很快失去可信度。

解法

添加规则是 「明示 → 直加，推断 → 确认」：用户明说的直接加，模型推断的必须过确认卡。题本是错因 + 意图两个正交维度，mastery 和归因只消费「有错因」的那部分，避免把「随便练的题」算进掌握度。返考也淡化「组卷」措辞，叫「复习 / 小测」。

D48 题本升格 · D47 知识资产归位

场用户觉得某个知识点「根本没那么难」，官方难度标错了+
解法

难度双层模型：个人覆写在本账号内免审核、即时生效（只改个人视图）；大量个人调整匿名聚合成众包信号，反哺官方校准。个人覆写与官方基线的落差本身就是画像信号——落差大 → 已掌握 / 偏科，直接喂 mastery。

D13 难度双层模型 · D27 知识页新增模块

场画像里冒出一条用户从没主动写过的条目，他想知道它哪来的+

隐式提取写入画像，用户会担心「它还记了我什么」——尤其在无对话历史的产品里，画像就是唯一记忆载体。

解法

三层保障：① 画像存的是提取后的结构化条目，不是原始流水，可看 / 可改 / 可删，但不能手动新建；② 画像 trace——每个条目能追溯到「哪次对话提取、置信度多少、用户改过没」；③ 边界清晰——学习域信号 + 生活域情绪基调进画像，具体事件 / 细节（当事人、冲突细节）一律不进；非知识类「毛病」进画像，库外知识只进归因、不进 mastery。

D50 画像体系 · D39 画像 trace · D10 可改不可新建 · D37 画像边界

场模型讲了一段特别好的非课内知识，用户想存下来以后看+

如果收藏只收「知识点」，这类内容就没地方去；如果存引用，原文到期就变死链。

解法

任意模型输出可收藏（含非课内知识、图片圈选区域），而且存快照不存引用。收藏不进知识点库、不参与 mastery / 难度 / 图谱；内容不可编辑但支持高亮与「虚化」自测；反复收藏覆盖并轻提示。归位上：题本 + 知识点记录 → 知识页（可评测），chat 收藏 → 个人中心（不可评测）。

D46 收藏体系 · D47 知识资产归位

场月考考砸了，想把这次失误和长期目标挂上钩+
解法

Exam 是独立实体，Goal 通过 examId + targetScore 引用它；错题可以标记来源考试；考后成绩回填是唯一能把「自评」与「客观结果」对上的数据，直接喂状态评估与画像。题本还能按教学课时排序（依赖知识点库课时字段，二期）。

D49 考试独立实体 · D48 题本 · §6 课时字段前置依赖

商业化、信任与边界

场用户担心用着用着就被悄悄扣 credits+
解法

两类处理：① 单次扣 credits 的动作（搜题 / 讲解 / 仿真）扣费前明示「将扣 X credits」，余额不足提示 + 引导订阅 / 签到；② 订阅用户不逐次显示扣费，走包月额度静默扣。更关键的是口径切分：嵌入式 AI 根本不进 credits——建议、复盘、口语转译、画像提取、推荐卡都是订阅权益，非订阅走规则模板降级。被计费的只有用户主动发起、有感的那部分。

D38 付费双模式 · §7 扣费知情

场不付费的用户，产品还剩什么可用？+
解法

总原则是规则免费、AI 计费：让用户免费看「状态如何」，为「AI 告诉我怎么办」付费。规则引擎产出的事实（状态、趋势、记录、掌握度）全免费；嵌入式 AI 非订阅时降级为规则模板，功能不断、表达变粗。credits 也能靠签到攒，弱化「花钱感」。

D38 付费双模式 · §0 分工铁律

场14 岁以下用户没做监护人授权就用上了群体参照+
解法

监护人授权是 <14 岁建档的强制门槛，归位在设置 →「授权与隐私」子页；入口两处、页面一处。开启群体参照前会校验授权。这一项属设计底线，不随合规暂缓跳过。

D41 监护人授权 · D42 设置瘦身

场用户担心产品天天推送「该学习了」，变成另一个焦虑源+
解法

通知只有三层：站内被动（推荐卡 + 角标）、本地（计时软提醒）、站外仅事务性邮件（验证码 / 找回密码 / 监护人授权）。不做学习提醒推送——这条是明确写死的，不是「暂缓」。

D44 通知三层

场用户担心「和相似的人」会暴露自己，或者被拿来排名+
解法

四道闸：① 分组按维度不按人，多维独立不交叉，绝不把维度做笛卡尔积切组（否则组崩空、凑不满 k）；② 最小群体 k = 20，不够就不生成该洞察；③ 自己的数给精确值，群体只给分位区间（P25 / P50 / P75），洞察卡底部标三要素、来源说明默认收起；④ L5 社交直接不做，是未成年红线。偏离预警不弹红点，必须带语义解释、区分正向与负向。

D18 按维度分组 · D19 分位数口径 · D35 L4 标注 · D12 L5 不做 · D33 偏离 ≠ 报警

场用户在闲聊里倾诉生活糟心事，情绪越说越重+
解法

三档定性 + 一条硬边界：L1 日常负面 → 共情 + 轻引导；L2 强烈负面 → 认真倾听 + 温和关注 + 提议求助；L3 明确危机 → 危机响应转介（接 safety_filter + CRISIS_RESPONSE），并覆盖 L2 → L3 的升级识别，不等到明说才反应。硬边界：学习助手 ≠ 心理医生，姿态是「识别 → 倾听（不评判）→ 转介」。情绪基调可进画像，具体事件细节不进。危机响应 prompt 基线是上线前补项。
