## 0. 一句话结论

三家的**功能展示手法**（界面截图、SDK 代码块、企业方案）对我们几乎全部不适用——受众不同，开发者懂界面语言，中学生懂"说话"的语言。
真正可迁移的是**叙事策略层**：把信任机制当卖点讲（Trae、Antigravity 已验证）、代际修辞要短（Antigravity）、真实用户墙（Qoder，pilot 后用）。
**最大收获**：教育产品全在卷提分，没有任何同行敢把「不评判、不排名、数据不出境、不替你做决定」当卖点——这是行业错位策略的第二次生效点。

## 1. 三站事实卡（抓取核实过的部分）

| 项 | Qoder（阿里） | Trae（字节） | Antigravity（Google） |
|---|---|---|---|
| 定位 | 智能体编程平台 | "The Real AI Engineer" AI IDE | agentic development platform |
| 叙事骨架 | 能力清单 → 产品家族（桌面/移动/IDE/插件/CLI）→ Agent SDK / Cloud Agents → 数字员工 → 企业版 → **真实用户墙** → FAQ | 排比式能力块 → **双模式**（IDE 手动 / SOLO 主导）→ **隐私与安全独立区块** | 「The tools of yesterday focused on helping you write code faster; the tools of tomorrow need to help you orchestrate it」代际宣言 → 双界面（Editor / Manager） |
| 功能展示 | 产品界面 mock 直接上 hero | 文案驱动，图少 | **「Artifacts, not logs」**：不给过程日志，给可核验产出物（计划/任务清单/diff/截图/浏览器录屏），像批注文档一样在产出上留反馈 |
| 最特别的一块 | 「他们用 Qoder 完成了什么？」实名用户墙 + 6,000,000+ 开发者 | 隐私单独成屏：「本地优先」「最小化数据收集」「区域化部署」 | "granular tool approval gates"（工具审批门）与 Ask-for-Review 模式当**卖点**讲 |

## 2. 值得借的四条

### 2.1 ⭐ Trae 的隐私区块，我们要做得更狠 → 新增「信任屏」

三家里只有 Trae 把隐私当独立卖点。我们面对未成年人，手里的牌更硬且**每一句都有真实工程背书**：

| 卖点句 | 背后的工程 |
|---|---|
| 「它不会替你做决定——每个动作都先问你。」 | 锚定确认卡（D17）/ 权限不给模型（#17 第三层） |
| 「你的错题和记录，不出这条链路。」 | 本地模型 embedding、数据不出境（PRD 12.6） |
| 「排名？这里没有。」 | 社区不做排名 / k 值 / 无社交 |
| 「监护人随时可以撤回，撤回即删除。」 | 监护人授权 + 撤回机制（合规底线） |

教育产品全在吹提分，没人敢把"不评判、不排名、数据不出境"当卖点——**行业错位第二次生效**。这一屏同时是给家长看的（此前悬而未决的"家长看什么"落点）。

### 2.2 Antigravity 印证了「权限不给模型」可以明说

它的 "granular tool approval gates" / "Ask for Review" 与我们 #17 第三层是同一条红线。外部最强团队把它当卖点，我们也该明说——对学生是掌控感，对家长是安全感。

### 2.3 代际修辞要短

Antigravity 的"昨天/明天"一句话讲完；我们第二屏用三张实景图讲同样的修辞，更重也更差异化，但**三个时代必须停在一屏内**，不能膨胀成两屏。

### 2.4 Qoder 用户墙句式，pilot 后直接抄结构

「他们用 Qoder 完成了什么」→「**他们用 EpochX 弄懂了什么**」。动词从"完成"换成"弄懂"，贴"记录弄懂的时刻"。pilot 期间匿名收集一句话反馈，脱敏后上墙。现在做不了，留位。

## 3. 不借的两条

1. **Trae 的对仗排比标题**（「工具自由装配，拓展能力边界」）：工整但 generic，与"一句轻话"路线正面冲突，学了就变广告腔。
2. **Qoder 的 hero 放产品界面**：受众是开发者，界面就是他们的语言。我们的受众是学生，语言是"说话"不是界面——**反向确认了 hero 放对话不放界面的判断**。别的产品 hero 放界面、我们放一段对话，这本身就是差异化。

## 4. 对 EpochX 落地页结构的影响

```
Hero（光场 + 暗纹手电 + 退格 slogan + 三级动作：输入框/即刻开始/桌面端按钮位）
  → 第二屏（斜向视窗·三个时代 +「AI 纪元，现围绕你构建」）
  → 功能屏 ×2~3（标题讲"你"的一句轻话，真对话/画面当证据，功能名降级小字）
  → 信任屏（新增 · 本笔记 §2.1 的四句话，给家长）
  → CTA 收尾（「围着你转」再现 + 输入框回收）
```
